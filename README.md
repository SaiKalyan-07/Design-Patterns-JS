# Design Patterns in JavaScript

A learning repository documenting JavaScript implementations of common
design patterns, with multiple variants per pattern showing the
progression from basic implementation to best practices.

## Patterns Covered
- [Singleton](./Singleton) — ensures a class has only one instance
- [Proxy](./Proxy) — controls access to an object via an intermediary

## Structure
Each pattern folder contains:
- Multiple `.js` files showing different implementation approaches
- A `README.md` explaining what each file demonstrates and key takeaways
